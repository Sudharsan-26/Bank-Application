# Banking Application
A backend banking management system developed using Spring Boot that provides RESTful APIs for managing users, bank accounts, transactions, and loan services. The application follows a layered architecture with Controllers, Services, Repositories, DTOs, and Exception Handling to ensure clean and maintainable code.

## Features
- User registration and management
- Bank account creation and management
- Deposit, withdrawal, and transaction history
- Loan application and management
- RESTful APIs with Swagger UI documentation
- Global exception handling
- Layered architecture following Spring Boot best practices

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Swagger (OpenAPI)

## Project Structure
- Controller Layer
- Service Layer
- Repository Layer
- Entity Layer
- DTO Layer
- Global Exception Handling

## Learning Outcomes
- Built RESTful APIs using Spring Boot
- Implemented CRUD operations with Spring Data JPA
- Managed database interactions using Hibernate
- Applied layered architecture and exception handling
- Documented APIs using Swagger
